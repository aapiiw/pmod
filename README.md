﻿# piwMod

Clash of Clans bot.

## Requirements

- Windows 10/11
- AutoIt v3.3.16 (run `MyBot.run.au3` as script)
- MuMu Player 12 (tested), Background Mode with WinAPI
- Microsoft Visual C++ 2010 Redistributable (x86), .NET Framework 4.5
